How to read these states

Comparable successors only

Omission counts advance only within a documented lineage with matching modality and use class. Unrelated releases never advance the sequence.

Uncertainty pauses derivation

When source coverage, lineage identity, successor order, or comparability is uncertain, the ledger uses an insufficient-evidence or quarantine state instead of advancing an omission count.

Public reporting only

A benchmark can be absent from reviewed public materials while still being used elsewhere. None of these labels describes undisclosed evaluation practice.
